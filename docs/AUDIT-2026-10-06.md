# Site audit — 2026-10-06

Eight read-only review agents (marketing+signup, catalog, scanner, inventory,
eBay+billing+account, backend+admin, mobile+design+speed, competitor research)
plus my own phone-size pass on prod. Nothing was changed. Items marked
(unverified) were not confirmed. Ranked within each section, worst first.

## A. Bugs people hit now

1. **Scanner: a scan that "took too long" is dead forever** — Scan Again and picking the card by name both silently do nothing for that row. `src/app/app/page.tsx:281-285, 387-391`, `CardEditor.tsx:476`. Clear `abandoned` on re-queue/pick.
2. **Scanner: the 20 s watchdog fires while work is still running** — the tiebreak call can take 30 s; after "Took too long" the card still gets saved, so Inventory gets a ghost card. `visionApi.ts:70`, `page.tsx:587, 707`. Cap tiebreak at ~5 s; check `abandoned` before saving.
3. **Scanner: a server timeout turns into a 14 s wait + wrong message** — the 504 "timeout" reason is dropped, the slow OCR fallback loads, and the seller is told "try a straighter, brighter shot". `visionApi.ts:148`, `page.tsx:533, 748`. Show "Took too long, tap Capture again" at once.
4. **Scanner: card shows Ready but was never saved** if the save call fails (no error shown, never reaches Inventory). `page.tsx:707-744`.
5. **Scanner: double tap on Capture can charge two scans for one card.** `CameraCapture.tsx:215`.
6. **Scanner: trial user who runs out mid-session loses the whole queue** — the paywall replaces the page. `SubscriptionGate.tsx:255`, `page.tsx:405`.
7. **Scanner: out-of-scans banner is hidden behind the open camera**; subscribers silently get worse OCR reads. `page.tsx:1327`.
8. **Scanner: removing a card while it saves leaves an orphan row in Inventory.** `page.tsx:1076`.
9. **Inventory: if loading fails it says "No cards yet — Scan Your First Card"** next to a red error that says "pull to refresh" (there is no pull to refresh). `collection/page.tsx:1115, 2453, 1765`.
10. **Inventory opens on the last game used even if it has 0 cards** and says "Nothing matches — try a different filter" when no filter is set (seen on prod: Lorcana 0 cards while Magic has 25).
11. **Sales Report shows an empty report when the fetch fails** — misleading for a tax report. `collection/report/page.tsx:27`.
12. **Set Completion: failures read as "no sets", a failed "show all" can't be retried, and cards already on the watchlist show "Watch" again.** `collection/sets/page.tsx:46-92`.
13. **Grid tile says "sold $X · net" but shows the gross price**; the sticker above shows net — two numbers disagree. `collection/page.tsx:2595` vs `:2518`.
14. **/pricing fee sentence is cut off: "$0.40 over )"** — the dollar amount is missing. `src/app/pricing/page.tsx:107`.
15. **Every plan card says "camera or photos"** — there is no photo upload. `PlanCard.tsx:15,28,42,54`.
16. **Catalog shows a price next to "this price looks off"** (Skyridge Charizard $2,999.99, labelled Reverse Holo). `cards/[game]/[set]/[card]/page.tsx:102-133`.
17. **Stale prices rank as "most valuable"** — Cavern of Souls $10,000, not updated in 2 months, "1,637x the set median". `lib/server/cardPages.ts`.
18. **YGO / Lorcana / One Piece top cards all stop just under $1,000** — looks like a price-guard ceiling hiding real top cards (unverified).
19. **No error page anywhere** — any crash shows Next's plain white "Application error" (worst in the TikTok browser). No `error.tsx`, `global-error.tsx`, `loading.tsx`.
20. **Tabs not highlighted on Insights / Report / Sets.** `AppTabs.tsx:50`.
21. **Focus outline squares off every round button** (`border-radius` in `globals.css:115-119`).
22. Smaller: price sort ignores quantity (`:1675`); bulk delete silently skips live/sold rows (`:1638`); market-value tile stuck on "…" if live prices fail (`:1204`); /scan flashes the camera button before "free scan used" (`TrialScanner.tsx:63`); profile page images have no fallback (`u/[handle]/page.tsx:60`); unreleased Star Trek set (Nov 2026) shows prices with no "preorder" label.

## B. Money, eBay and account risks

1. **One bad eBay token reply deletes the seller's eBay link** — rotating the eBay secret would disconnect every seller (stored tokens are encrypted with the secret too). `ebayAuth.ts:169-172, 519-523`. Only drop on `invalid_grant`; separate `EBAY_TOKEN_KEY`.
2. **eBay sales sync can double-count a sale** (two tabs / crash mid-step). `ebayOrders.ts:119-150`.
3. **Ended-listing check only ever looks at the same first 25 listings.** `ebayListings.ts:88`.
4. **A 100%-off Stripe promo code would grant full scans every month.** `billingCredits.ts:101-112`.
5. **eBay sync failures retry on every page load** and eat the eBay API cap. `ebayOrders.ts:162`, `ebayListings.ts:112`.
6. **Publish can go live on eBay without our row being marked listed**; a retry then errors. `ebaySell.ts:856-883`.
7. **/connect-ebay copy is out of date** — says "you publish every listing yourself on eBay" and "listings open pre-filled". `EbayConnectCard.tsx:126,138`.
8. **First publish silently creates eBay shipping ($4.99 flat), returns and location policies** — not disclosed anywhere. `ebaySell.ts:219-254`.
9. **The "set up policies" link always points to ebay.com** — wrong for UK/IE/AU/CA. `EbayPostActions.tsx:349`.
10. Changing your email never updates Stripe (receipts go to the old address). Deleting an account leaves live eBay listings up. Password change rate-limited per IP only. eBay link expiry (~18 months) never warned. Referral reward lost if the referrer isn't subscribed yet; never clawed back on refund. Trial "Selling comes with a plan" doesn't mention the Scan Pack also unlocks it.
11. Copy that hardcodes numbers outside pricing.ts: home FAQ "$5/$10" (`page.tsx:64`), rewards "Five scans" / "Ten friends is a thousand scans" (`rewards/page.tsx:21,178`).

## C. Ad funnel and signups (TikTok traffic is landing now)

1. **TikTok pixel only fires on signup** — add "ViewContent" when a price shows and "ClickButton" on the signup tap so TikTok learns from far more events. `lib/client/pixel.ts:22`.
2. **/scan: after the free price, put a pinned "Your card is waiting — create an account to keep it" bar** with their own photo next to the price. `TrialScanner.tsx:152-168`.
3. **/scan "used" screen: show their card's price** ("Your Charizard is worth $412 — get 5 more scans") instead of a generic message.
4. **/scan miss / busy: no signup button there**, only Try Again. `TrialScanner.tsx:79-81,196-206`.
5. **Signup asks for full name** — drop it (only used for a greeting); consider Sign in with Google/Apple.
6. **After signup, "How will you use it?" stands between the user and the scanner** — default to Collector and go straight to the scanner. `signup/page.tsx:262-285`.
7. **`?from=scan` on every /scan signup link is read by nothing** — can't tell ad signups apart.
8. FAQ says "Do I need my own eBay account? Yes" — wrong for Collector mode. `page.tsx:68-70`, `pricing/page.tsx:80-82`.
9. /scan on a phone: everything sits in the top third, two thirds empty below (prod screenshot). Add social proof ("X cards priced"), a 3-step how-it-works, or a sample card.
10. Per-game /scan links (`/scan?game=magic`) so each ad lands on its game.

## D. Quality-of-life fixes

1. **Public catalog has no search box** — someone from Google on one card can't look up another. Add search to /cards, game pages and the top nav.
2. **Card page CTA is always "Scan Yours Free"** — add "Watch this price" / "Add to my collection" that carries the card into signup.
3. **Set pages stop at 300 cards** with no "show more". `cardPages.ts:61`.
4. **Undo instead of "are you sure" on delete** (the watchlist already has an Undo toast to copy).
5. **Set Completion is Pokémon only**; Insights link hidden for the other four games though it works for them.
6. **Help robot and invite text talk about eBay to Collector-mode users.** `HelpPanel.tsx:60-67`, `rewards/page.tsx:66`.
7. Inventory search only matches name/set/number — add rarity, condition, category; add A–Z and Set sorts, "Duplicates" and "Missing price" filters.
8. Bulk actions: set price / condition for many cards at once.
9. "Not this card?" button right on the camera result chip (today you have to leave the camera to fix a wrong match).
10. "Verify all" screen after a stack scan instead of verifying cards one by one.
11. 429 "too many / try tomorrow" responses show as a generic read failure — say what happened.
12. Condition ladder on card pages is a fixed % formula labelled "eBay Suggested Price" — label it "estimate".
13. Wrong/old card URLs get a bare 404 — add a search box + game links; app 404 should keep the app tabs.
14. Long Inventory lists render every card at once — page in 60 at a time.

## E. Look and feel (makeover)

1. **Loading skeletons + friendly error screen + app 404** (nothing today between a tap and the content or a crash).
2. **Contrast pass** — ~800 places use grey text too faint on our near-black (zinc-500/600), often at 8-11 px. One floor: zinc-400 and 12 px minimum. Biggest readability win outdoors on phones.
3. **One shared bottom-sheet for all pop-ups** (card detail, peek, confirm, category, eBay, sealed, help) — slides up on phones, Escape/back closes it, focus stays inside.
4. **Bigger tap targets + a bottom tab bar on phones** (tabs are ~36 px tall at the top; scanner should be one thumb away).
5. Catalog tiles are blank black boxes while pictures load — add a shimmer placeholder.
6. Card page on phones: sticky bottom bar with price + one button; move "About" under the chart.
7. Inventory row/tile: too many buttons per row on phones — move the extras into a "⋯" menu.
8. Inventory game pills are cramped at phone width ("One Piece · 1Yu-Gi-Oh! · 0" run together).
9. Account page: "Free trial" badge next to "Early account · 100/100 scans today" contradicts itself.
10. Home page title is 95 characters (cut off in Google).

## F. Behind the scenes (speed, cost, safety)

1. **Every logged server warning reads ~500 rows to prune the error log** — a log storm burns Turso reads. `errorLog.ts:56`.
2. **page_views and 7 other log tables grow forever** — add a weekly cleanup.
3. **Admin overview full-scans the cards table on every load** — add an index + 1-5 min cache. `adminStats.ts:271-277`.
4. **Public set/featured APIs have no cache header and no rate limit** — a scraper costs real reads.
5. **Weekly digest and sealed crons aren't scheduled** — confirm the daily job really sends the digest (unverified).
6. **Backups run from Chris's PC** — if it's off nothing backs up and nothing alerts. Add a "backup older than 30 h" alarm; same for "last price run older than 36 h".
7. Billing/push rate limits are per-server-instance only — switch to the DB-backed limiter.
8. Untracked `scripts/.stripe-address-tmp.mjs` reads the Stripe secret — delete or gitignore.
9. Admin password fallback should refuse to run anywhere but local dev.
10. Cron secret also accepted in the URL (`?key=`) — can land in logs.
11. Five small components load on every public page (incl. the egg file) — merge the two attribution ones, lazy-load analytics.
12. Big client components (CardEditor, CameraCapture, chart, help) — load them on demand.
13. Admin "needs attention" strip: backup age, last price run, errors 24 h, open tickets, Turso usage.
14. A CI test that fails when a new API route has no auth check.

## G. New feature ideas (ranked by payoff vs effort)

1. **Price confidence badge** — "based on N sales", low-data flag. #1 complaint about Collectr/Ludex is wrong prices.
2. **Share image of a scan / collection value** (TikTok/Reddit-ready 1080x1920) — free marketing.
3. **Top movers page per game** (`/cards/pokemon/movers`) — SEO + a reason to come back.
4. **"Near 90-day high/low" note on charts** — we already have the data.
5. **Annual plans** (~25-35% off is the market norm; billing credits need adjusting).
6. **Wishlist "buy now" link to the cheapest eBay listing** (affiliate revenue).
7. **Multiple binders/folders** (Binder, For sale, PC) — Collectr's most-liked feature.
8. **Pack-opening tracker** — scan your pulls, see pack cost vs value, share "my pack ROI". Fits the TikTok opening crowd.
9. **Value-based shipping** — tracked/insured above a price instead of $4.99 flat on a $500 card.
10. **Best Offer with auto-accept / auto-decline floors.**
11. **"Card missing? Tell us" button** on a catalog miss, with a notify-me email.
12. **Camera tips overlay** (glare, sleeves) before capture — cuts failed scans.
13. **Variant warning** — "this looks like the Special Illustration version, $X more".
14. **Graded values (PSA 9/10) next to raw on card pages** (slabs stay blocked from scanning).
15. **Collection value header for Collector mode** — total, week change, top movers.
16. **Offline "No signal" page** for card shows + home-screen shortcuts (Scan, Inventory).
17. **Previous/next card in set on card pages.**

Marketing angles competitors are weak on: honest prices with receipts; scans that never stall; no nag paywall; nothing to lose (web account + nightly backup); scan → price → listed on eBay in 30 seconds (none of them list).

Competitor pricing: Collectr Pro $7.99/mo or $59.99/yr; Ludex $4.99 / $9.99 / $24.99 a month; Card Ladder Pro $19.99/mo. Market sits at ~$5-8/mo for collectors, $20-25 for power users.
