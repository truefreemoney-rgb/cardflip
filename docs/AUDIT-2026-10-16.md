# Site audit 2026-10-16 (8 agents + live phone crawl)

Read-only. No Critical or High security holes. CI + smoke green on d4c436e1.

## Fix first (Medium)
1. eBay comps cache poisoning — `ebayCompsCache.ts:21` keys on client `card.id`, query built from client `card.name`. Real id + fake name poisons that card's comps for 24h for every seller, and graded runs write junk into the real card's graded history (`ebay/comps/route.ts:127-136`). VERIFIED. Fix: load the catalog card by id server-side and build the query from it.
2. Signup pre-hijack — `emailVerify.ts:430-468`: attacker signs up with victim's email; victim confirms; attacker's password + session stay live. Fix: on confirm, wipe password + other sessions unless the confirming browser holds the signup session.
3. Google/X link leaves the other provider id — `users.ts:615-641`: clear `x_sub` in linkGoogleSub unproven branch (and `google_sub` in linkXSub).
4. Cron GETs accept admin cookie (SameSite=Lax) — `cron/emails`, `cron/social-tiktok`, `cron/social-video`, `cron/social-inbox`: a link Chris clicks can fire `?force=1`. Copy `cookieAllowed` from `social/publish`.
5. Login lockout per email only — 10 bad tries lock Chris/admin out 15 min. Key on email+IP.
6. Vision scan→giveback loop — empty reads refunded, Sonnet still billed; ~$5.50/day/account. Cap free empty reads/day. Also tiebreak allowance counts refunded reads (`vision/scan/route.ts:122`).
7. $0 paid invoice credits a full plan (`billingCredits.ts:99-112`, promo codes allowed). Require `amount_paid > 0` or kill 100%-off codes.
8. Trial farming — cookie + IP + Gmail key only. Add daily global new-trial cap + /24 subnet limit.
9. Duplicate emails — send before log (`campaigns.ts:560`, `digest.ts:240`). Claim row before send.
10. `quantity` up to 99 accepted on eBay push/draft — force 1 for kind "card" (one card per listing).

## Low
- Refund/dispute doesn't cancel sub; `past_due` counts as subscribed indefinitely.
- In-memory rate limits don't bind on serverless: search-card, sets, set-cards, sealed/price, price-history, share/card (expensive render, public).
- Admin cookie stateless (logout can't revoke; touch keeps it alive); admin key falls back to "cardflip" if EBAY_TOKEN_KEY/CLIENT_SECRET unset.
- Login reveals Google-only accounts; signup 409 enumerates.
- No session revoke on 2FA disable / email change; no absolute session max age.
- DevLoginButton bakes "admin"/"password" defaults into prod bundle (inert unless NEXT_PUBLIC_DEV_LOGIN set).
- Unsubscribe is GET (prefetchers can unsubscribe).
- No per-user row cap on cards/price-checks/wishlist POST.
- ebay offers/reprice/end skip sellingGate; eBay account can link to several users; callback decodeURIComponent can 500.
- vision/trial `image` not type-checked; tiebreak `ids` unbounded; push bad endpoint → 500.
- Soft 404s on unknown card/set slugs (noindexed); robots `Disallow: /app` also blocks /apple-icon.png.
- No CSP (intentional); HSTS no preload; npm audit 1 high (source-map-js, build-time only).
