# Magic look-alike printings: read cues (research 09-29)

Pulled from the live Scryfall API. Items marked (unverified) are from memory. Use this when a panel bucket misses.

## Scryfall number suffixes
- `187s` = prerelease (gold date stamp, foil only, promo set `pXXX`). `187p` = Promo Pack (planeswalker-symbol stamp). Both share the base number with the main-set card, so **the stamp decides**.
- `★` = the foil-only twin of a plain number (`9ed/242★`, `pm10/166★` release promo with a date stamp, `40k/86★` surge foil). It is not a printed star rarity.
- `z` = serialized or double-rainbow (`brr/64z`, `ltr/746z`, `mkm/317z`). The card shows a printed serial "n/500".
- `a–d` = the same card in several arts (`ust/3a`, `unf/200a`). `Φ` = step-and-compleat (sld).
- Art Series signed = `amh2/28s`, `astx/70s`. **Only MH2 and STX** have signed rows on Scryfall. TCGplayer also sells signed ZNR and KHM, but Scryfall has no row for them.
- The List = `plst/MH2-123`: the source set plus its number, with a **planeswalker symbol at the bottom left**.
- Media inserts = `pmei/2025-25`. 30th Anniversary = `p30m/1F`, `1P`, `1★`.

## Promo families
- Bundle: foil alternate art or frame, **in the main set at a high number** (`mh2/489`), no stamp.
- FNM `fXX`, judge `jXX`/`gXX`, Store Championship `sch`: plain numbers in their own set.
- 2009–10 release promos (pm10, pm11, p9ed): date stamp plus `★`.

## Special foils (a photo cannot reliably tell surge from rainbow from galaxy)
Etched (flat metallic, no rainbow; Commander, mh2, clb, 2x2, cmm) · galaxy (unf, sld) · surge (40k, who, pip, ltc) · textured (raised ridges; dmu, otp, mh3, 2x2) · serialized (`z`) · confetti · neon ink (lci 410a–f, neo, fin) · step-and-compleat (one, sld) · halo (mul, mat) · oil slick (one) · ripple (m3c) · gilded (snc) · scroll (ltr) · invisible ink (mkm).
Rule: identify by set and number first. Treat the finish as a hint only.

## Frames
Showcase · borderless · extended art (art runs into the text margins) · retro 1997 · future sight · inverted/legendary crown (dbl, sch, dsk, inr, fdn; often etched) · Secret Lair `sld` (borderless).

## Bottom line by era (unverified)
Pre-M15: `n/total` plus copyright. M15–2022: number/total, rarity letter, set code, language, artist. 2023+: number, rarity letter, set code, language on one line. A `P` in the set slot means a promo. `•` = non-foil, `★` = foil.

## Masterpieces and Un-sets
Masterpieces (`exp`, `mps`, `mp2`): foil only, plain numbers. Un-sets: silver border (ust) or acorn stamp (unf). Mystery Booster playtest: `cmb1`, `mb2`.
